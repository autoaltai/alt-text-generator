=============================
AutoAlt.ai Alt Text Generator
=============================

:Extension key:
    alt_text_generator

:Package name:
    autoaltai/alt-text-generator

:Version:
    |release|

:Language:
    en

:Author:
    AutoAlt.ai

:License:

:Rendered:
    |today|

----

Generate accessible, SEO-friendly image alt text for TYPO3 media assets using
the AutoAlt.ai API. The extension scans the File Abstraction Layer (FAL) for
images missing alt text, generates it individually or in bulk, can generate
alt text automatically whenever an editor uploads a new image, and keeps a
filterable retained history and system log of generation attempts.
